# صبحانه‌سرای آفتاب — نرم‌افزار مدیریت رستوران

نرم‌افزار **کامل مدیریت صبحانه‌سرای آفتاب** به‌صورت وب‌اپلیکیشن استاتیک (Static Web Application) — بدون سرور، بدون بک‌اند و بدون پایگاه‌داده خارجی؛ تمام داده‌ها در مرورگر کاربر (IndexedDB) ذخیره می‌شوند.

> زبان رابط: فارسی | راست‌چین کامل | واحد پول: تومان | تقویم: شمسی | قابل نصب: PWA | اجرا: آفلاین

### قوانین مالی پیاده‌شده
- محاسبه خودکار بهای تمام‌شده غذا از رسپی و **میانگین موزون** مواد
- سود ناخالص و خالص در هر بازه زمانی
- ثبت نقدی، کارت‌خوان و **پرداخت ترکیبی** و **نسیه** (با پیگیری طلب)
- ثبت خرید و بدهی تأمین‌کنندگان + پرداخت
- ثبت هزینه‌ها و **جلوگیری از دوباره‌شماری** (uniqueKey + قالب دوره‌ای)
- محاسبه گردش نقدی صندوق (کارت‌خوان جدا از صندوق نقدی)
- ثبت ضایعات با ارزش‌گذاری و لحاظ در سود و زیان
- حفظ سوابق قیمت خرید در اسناد و گردش انبار
- کسر خودکار مواد بر اساس رسپی پس از ثبت فروش (و بازگردانی کامل هنگام حذف)

### قوانین انبار
- واحد پایه + واحدهای تبدیل دلخواه (مثلاً کیلوگرم←گرم)
- ورود/خروج، ضایعات، تاریخ انقضا، هشدار حداقل موجودی
- شمارش واقعی و اعمال اختلاف، گزارش گردش مواد

## اجرا

پروژه نیاز به هیچ بیلد یا سروری ندارد:

```bash
# راه‌اندازی محلی (هر سرور استاتیکی کافی است)
python3 -m http.server 8080
# سپس http://localhost:8080
```

فایل `index.html` را می‌توان مستقیم هم باز کرد، اما برای Service Worker (آفلاین و نصب PWA) لازم است از طریق `http(s)` سرو شود.

### انتشار روی GitHub Pages
1. مخزن را در GitHub منتشر کنید.
2. Settings → Pages → Source: `main` و پوشه `/` (ریشه).
3. همه مسیرها نسبی (`./`) هستند؛ بنابراین در زیرمسیری مثل `https://user.github.io/Resturant/` هم کار می‌کند.

## فناوری‌ها

- HTML5 / CSS3 / JavaScript ES6+ (ماژولار، بدون هیچ فریمورکی)
- IndexedDB (داده‌ها) • LocalStorage (تنظیمات)
- Chart.js • SheetJS (اکسل) • jsPDF + html2canvas (PDF با متن فارسی صحیح)
- Service Worker + Web App Manifest (PWA، آفلاین، دکمه نصب روی دستگاه)
- الگوریتم رسمی تقویم شمسی (`jalaali-js` — MIT، به‌صورت محلی)
- فونت **Vazirmatn** (متغیر، محلی)

> همه کتابخانه‌ها در پوشه `vendor/` و `fonts/` نگهداری می‌شوند؛ برنامه **بدون اینترنت هم** کار می‌کند.

## ساختار پوشه‌ها

```
├── index.html              # پوسته برنامه
├── manifest.json           # PWA
├── sw.js                   # Service Worker (آفلاین)
├── css/                    # تم، چیدمان، اجزای UI
├── js/
│   ├── app.js              # روتر و راه‌اندازی
│   ├── core/               # db, utils, jalaali, money, settings, exporters
│   ├── services/           # منو، انبار، فروش، خرید، صندوق، هزینه، گزارش، پشتیبان
│   ├── pages/              # ۱۴ صفحه منو
│   └── ui/                 # مودال، توست، جدول‌ها
├── vendor/                 # Chart.js, SheetJS, jsPDF, html2canvas + LICENSE
├── fonts/                  # Vazirmatn + LICENSE
├── icons/                  # آیکون‌های PWA
└── tests/run.mjs           # تست‌های جامع (۶۶ تست)
```

## تست

```bash
npm install
npm test
```

تست‌ها شامل موارد زیر هستند:
- دقت تقویم شمسی (نوروز ۱۴۰۲ تا ۱۴۰۵، کبیسه، پیمایش روزها)
- محاسبات مالی (میانگین موزون، بهای رسپی، پرداخت ترکیبی، سود)
- چرخه کامل: منو → ماده اولیه → خرید → رسپی → فروش → کسر انبار → صندوق
- دریافت طلب نسیه و بازگردانی کامل هنگام حذف فروش
- جلوگیری از دوباره‌شماری هزینه و حقوق
- **سلامت داده‌ها**: تطابق انبار با گردش اسناد، جمع‌های فروش، طلب نسیه، یکتایی هزینه‌ها + اصلاح خودکار
- پشتیبان‌گیری و بازیابی کامل
- راه‌اندازی برنامه، ناوبری هر ۱۴ صفحه و تعامل کامل POS در jsdom

## حریم خصوصی و ذخیره‌سازی

- هیچ داده‌ای به سرور ارسال نمی‌شود؛ همه چیز در مرورگر خودتان می‌ماند.
